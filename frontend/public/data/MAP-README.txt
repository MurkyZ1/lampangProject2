ขอบเขตตำบลของจังหวัดลำปาง (13 อำเภอ)
===================================
โปรเจกต์นี้ใช้ TopoJSON ของ GeoThai/boundaries v2026.10.23

ดาวน์โหลดไฟล์สำหรับใช้งานแบบไม่พึ่งอินเทอร์เน็ต:
  npm run map:download
(รันจากโฟลเดอร์หลัก)

หรือดาวน์โหลดไฟล์จาก:
https://cdn.jsdelivr.net/gh/GeoThai/boundaries@v2026.10.23/datawrapper/subdistricts/52.topojson

บันทึกชื่อเป็น lampang-subdistricts.topojson ในโฟลเดอร์นี้

ที่มา: GeoThai, from OCHA COD-AB and Royal Thai Survey Department.
ลิขสิทธิ์ข้อมูลขอบเขต: CC BY 3.0 IGO
ชื่อและรหัส: GeoThai/data, CC BY 4.0
ลิงก์: https://github.com/GeoThai/boundaries

หมายเหตุ: เส้นแบ่งตำบลไม่ได้บอกคุณสมบัติดิน พืชที่เหมาะสม หรือเขตชุมชน
