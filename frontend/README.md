# React Frontend

โปรดอ่าน `../README.md` สำหรับคำสั่งรัน การเจาะแผนที่ตำบล และการทำงานของระบบสมาชิก / แอดมิน

## หน้าเว็บ
- `/` — หน้าแรก แผนที่ 13 อำเภอ → คลิกอำเภอแล้วแสดงรูปทรงตำบลจริงพร้อมเส้นแบ่งและชื่อ (GeoThai TopoJSON) → คลิกตำบลเพื่อดูข้อมูลด้านขวา; คลิกชนิดพืชเข้าสู่คู่มือ; รายงานชุมชนที่อนุมัติแล้วแสดงด้านขวาของแผนที่
- `/tambons` — ค้นหาและนำเข้าข้อมูลระดับตำบล/ชุมชน
- `/crops` — คู่มือพืช (พืชที่ยังไม่อยู่ในคู่มือจะแสดงสถานะว่าข้อมูลไม่ครบ)
- `/soil` — เครื่องมือคัดกรองคุณสมบัติดิน
- `/dashboard` — เปรียบเทียบสภาพดินหรือการเพาะปลูก ระหว่างอำเภอหรือตำบล
- `/limitations` — ข้อจำกัดของข้อมูลและโมเดล
- `/community` — ส่งรายงานเมื่อเข้าสู่ระบบ และดูรายงานที่อนุมัติแล้ว
- `/auth` — เข้าสู่ระบบ / สมัครสมาชิก
- `/admin` — ตรวจสอบและอัปเดตรายงาน (เฉพาะบัญชีแอดมิน)

แชตยังเป็นปุ่มลอยมุมขวาล่างเท่านั้น

## ข้อมูลขอบเขตสำหรับแผนที่
รัน `npm run map:download` ในโฟลเดอร์หลักเพื่อเก็บไฟล์ TopoJSON ใน `public/data/lampang-subdistricts.topojson` หรือเปิดเว็บผ่านอินเทอร์เน็ตเพื่อโหลดจาก GeoThai CDN อัตโนมัติ การมีเส้นแบ่งตำบลไม่ได้หมายความว่ามีข้อมูลค่าดินระดับตำบล ต้องนำเข้า Data ตาม `public/templates/tambons-template.csv` แยกต่างหาก ดูรายละเอียดและใบอนุญาตใน `../README.md`
